# AushadhiTrack — SIH 2026 Prototype

A clickable, zero-dependency prototype for SIH problem statement **SIH26198**. It reconciles Jan Aushadhi dispatches, point-of-sale sales, write-offs, and reported inventory.

## Run locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 4173
```
